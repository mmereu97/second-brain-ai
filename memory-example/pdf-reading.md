metadata:
  type: feedback
---
Large PDFs: extract the text once, page by page, into `<name>.txt` next to the PDF with markers `=== PAGE N ===`. Scanned manuals are transcribed once (one language only).
**Why:** searching text is fast and lets every answer cite the page.
**How to apply:** look for the `.txt` first; create it only if missing.
